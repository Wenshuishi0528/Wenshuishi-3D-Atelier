## 制作理念

- **先看整体，再看细节。** 以实物图片和多角度参照校正轮廓，再逐步处理窗框、刻线和连接处。
- **兼顾外观与小比例制作。** 让细节服务于模型的识别度，并结合打印尺寸考虑厚度与强度。
- **记录有意义的变化。** 用清楚的前后对比呈现调整，区分数字验证和实际打印结果。
